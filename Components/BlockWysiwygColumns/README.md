# Block Wysiwyg Columns

JGI "Text Columns" block: an optional left-hand serif heading beside 1–3 WYSIWYG
content columns.

- **Title** — optional heading, `Lead` (`font-h2`) or `Label` (`font-h5`) style, dark-green.
- **Columns** (1–3) — each a WYSIWYG with an optional `Checklist` list style
  (bullet lists render with a check-in-circle icon) and an optional button
  (`button--primary`).
- **Options** — background colour.

Covers the three Figma variants: heading + checklist, heading + text + button,
and heading + multi-column text.
