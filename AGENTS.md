## TL;DR

This is a **Flynt-based WordPress theme** (`jgi`) for Jane Goodall Institut Deutschland, built and
deployed via the `wp-build-agent` pipeline. Stack: PHP / Timber-Twig / Tailwind / Alpine.js /
ACF Pro / Vite, on DDEV locally. The studio's TypeScript / pnpm / Biome / Sanity defaults do
**not** apply here.

## Dominant pattern — the Flynt component

A component is a self-contained block under `Components/<Name>/`, and its files land together
in one commit:

1. `functions.php` — namespaced `getACFLayout()` returning the ACF field definition.
2. `index.twig` — markup, Tailwind classes, Alpine.js.
3. `script.js` — component JS (optional).
4. `style.scss` — component styles (Vite → `dist/`).

Then **register** the component in a field group under `inc/fieldGroups/`. An unregistered
component is half-wired. **Reuse before invention** — grep `Components/` first.

## Tooling order — verify before done

- `composer install` / `npm install` / `npm run build` (Vite). Dev: `npm run start` (HMR).
- PHPCS against `phpcs.xml.dist`; `php -l` on changed PHP.
- Visual + a11y check before deploy.

## Commits — Conventional Commits

`type(scope): summary`, imperative, lower-case, no trailing period. Scopes: `component`,
`template`, `style`, `acf`, `i18n`, `build`. A component's four files + its field-group
registration land in **one** commit.

## Anti-patterns / never touch

- No secrets in the repo. Don't hand-edit `dist/` (generated by Vite).
- Don't invent new top-level folders — follow the Flynt structure (`Components/`, `inc/`,
  `lib/`, `templates/`, `assets/`).
- Required plugins are loaded as must-use by the pipeline; don't duplicate them as normal plugins.

## Definition of done

- `npm run build` clean; PHPCS clean on touched PHP.
- New/renamed component: four files **and** field-group registration in one commit.
- No secrets committed. Conventional Commit message.
